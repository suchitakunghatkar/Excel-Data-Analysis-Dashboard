# 📊 Excel Data Analysis & Interactive Dashboard

## 📌 Project Overview

This project focuses on analyzing employee working hours, efficiency, break patterns, and call performance using Microsoft Excel.

An interactive Excel dashboard was developed to transform raw employee-level data into meaningful performance insights using Pivot Tables, Pivot Charts, Excel formulas, and VBA-based dashboard controls.

The project demonstrates how Excel can be used for data cleaning, analysis, visualization, reporting, and interactive dashboard development.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze employee working hours and productivity
- Evaluate employee efficiency and customer-active time
- Analyze employee break patterns
- Understand call handling performance
- Compare employee-level performance
- Identify areas for productivity improvement
- Build an interactive Excel dashboard
- Use VBA to improve dashboard navigation and interactivity

# 📊 Key Numerical Insights

The analysis was performed on **149 employee records**.

### ⏱️ Working Hours & Productivity

- **149 employees** were analyzed.
- Average total working time was **8.02 hours per employee**.
- Total recorded working time was approximately **1,195.07 hours**.
- Average work-efficiency time was **4.40 hours per employee**.
- Total work-efficiency time was approximately **650.60 hours**.
- The highest recorded working time was **9.28 hours**.
- The highest recorded work-efficiency time was **5.87 hours**.

### 📈 Efficiency Performance

- Overall average employee efficiency was **71.61%**.
- The highest recorded efficiency was **87.79%**.
- **26 employees** achieved an efficiency of **75% or higher**.
- **4 employees** achieved an efficiency of **80% or higher**.
- Average customer-active time was **50.68%**.
- **95 employees** recorded customer-active time of **50% or higher**.
- Average non-working time was **21.00%**.
- **45 employees** recorded non-working time above **25%**.

### 📞 Call Performance

- Employees handled a total of **9,404 attended calls**.
- Average attended calls were approximately **63 calls per employee**.
- The highest number of attended calls by a single employee was **107 calls**.
- Average call duration was approximately **4.10 minutes**.
- The dataset recorded approximately **16.21 hold calls** across the employee-level performance records.

### ☕ Break Analysis

The total recorded break time across all employees was approximately **287.54 hours**.

Break time was distributed across the following categories:

| Break Category | Total Hours |
|---|---:|
| Lunch | 88.61 hours |
| Normal Break | 68.47 hours |
| Other Work | 43.37 hours |
| Meeting | 39.92 hours |
| Training | 22.77 hours |
| Feedback | 18.98 hours |
| Unwanted Break | 2.01 hours |
| **Total Break Time** | **287.54 hours** |

Lunch was the largest individual break category, accounting for approximately **88.61 hours**.

# 💡 Business Insights

Based on the analysis, several important observations were identified:

### 1. Employee Efficiency

The average employee efficiency was **71.61%**, while the highest recorded efficiency was **87.79%**.

This indicates variation in employee productivity and provides an opportunity to identify practices followed by higher-performing employees.

### 2. Productive Working Time

Employees worked an average of **8.02 hours**, while average work-efficiency time was approximately **4.40 hours**.

This difference highlights an opportunity to investigate how working time is distributed between productive activities, breaks, calls, and non-working activities.

### 3. Non-Working Time

The average non-working percentage was **21.00%**.

Furthermore, **45 employees** recorded non-working time above **25%**, making this an important area for further performance investigation.

### 4. Customer Interaction

Average customer-active time was **50.68%**, with **95 employees** recording customer-active time of at least **50%**.

This indicates that customer interaction represents a significant portion of employee activity.

### 5. Call Handling

A total of **9,404 attended calls** were recorded, with an average of approximately **63 calls per employee**.

The highest individual call volume was **107 calls**, showing variation in call workload among employees.

### 6. Break Utilization

Employees recorded approximately **287.54 total hours of break-related activity**.

Lunch breaks represented the largest category at **88.61 hours**, followed by normal breaks at **68.47 hours**.
